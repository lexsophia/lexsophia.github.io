TEAP Reading Part 2B（大学掲示・メール読解 5問） 対策 ＆ 無料演習

Part 2Bは履修登録・図書館の開館時間・寮の退去手続き・奨学金応募・課題提出など、大学キャンパスで実際に見かける掲示やメールから条件・例外・締切・対象者を正確に読み取るパートです。

Part 2B 専用演習 推奨時間目安：8分（独自設計） 全問 和訳・根拠・誤答理由つき
読み込み中...

Part 2B 攻略の3ポイント

  • unless / only if / except / however など「例外条件」を示す語に必ず注目する。
  • 設問の日付・立場（1年生か3年生か、締切前か後か）を本文の条件と照合する。
  • NOT問題（利用できないサービス等）は該当する3つを消して確実に1つを残す。
